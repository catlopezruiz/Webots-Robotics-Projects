# Webots Robotics Projects

A collection of autonomous robotics projects developed using Java and Cyberbotics Webots as part of my Computer Science coursework at California State Polytechnic University, Pomona.

## Technologies Used
- Java
- Cyberbotics Webots
- E-puck Mobile Robot
- Infrared Proximity Sensors
- Autonomous Navigation Algorithms

## Project 2: Collision Avoidance

Developed an autonomous robot controller capable of detecting obstacles and adjusting its movement to avoid collisions.

**Key Features:**
- Utilized eight infrared proximity sensors to detect surrounding obstacles.
- Implemented obstacle avoidance using sensor-based decision-making.
- Adjusted individual wheel velocities to navigate around obstacles.
- Tested robot behavior across multiple simulation scenarios.

## Project 3: Maze Navigation

Developed a Java-based controller to autonomously navigate an e-puck robot through simulated maze environments.

**Key Features:**
- Implemented wall-following navigation algorithms.
- Used proximity sensors to detect walls and obstacles.
- Adjusted turning behavior and movement speed based on sensor readings.
- Implemented destination detection to stop the robot at the maze exit.

## Project 4: Autonomous Navigation

Developed autonomous navigation software using potential-field-based navigation techniques in Webots.

**Key Features:**
- Implemented goal-directed robot navigation.
- Used sensor readings to detect and avoid obstacles.
- Adjusted robot movement in response to the surrounding environment.
- Implemented goal detection to stop the robot upon reaching its destination.
